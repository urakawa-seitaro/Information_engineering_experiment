Bleach Correction のインストール (Windows 64-bitの場合)

ソースの入手

  • ブラウザを開いてBleach Corrector にアクセス
    • Installation にある「CorrectBleach_.jar」を右クリックして，「名前を付けてリンクを保存」

インストール

  • ダウンロードしたファイル CorrectBleach_.jar を，AstroImageJのフォルダーの下にある「plugins」というフォルダーに移動

確認

  • AstroImageJ を起動する
    • 起動済みの場合はいったん終了して，再度起動する
  • Plugins -> EMBLtools -> Bleach Corrections が見えたらOK



Bleach Correction のインストール (Macの場合)

ソースの入手

  • ブラウザを開いてBleach Corrector にアクセス
    • Installation にある「CorrectBleach_.jar」をクリックして，ダウンロード

インストール

  • 「アプリケーション」フォルダーを開く
  • 「AstroImageJ」を「control」キーを押しながらクリック，「パッケージの内容を表示」を選んで，フォルダーを開く
  • 「Contents」というフォルダーがあって，その下に「Resources」というフォルダーがあって，その下に「plugins」というフォルダーがあるはず
  • ダウンロードしたファイル CorrectBleach_.jar を「plugins」というフォルダーに移動する

確認

  • AstroImageJ を起動する
    • 起動済みの場合はいったん終了して，再度起動する
  • Plugins -> EMBLtools -> Bleach Corrections が見えたらOK
