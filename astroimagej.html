AstroImageJ のインストール (Windows 64-bitの場合)

  • ブラウザを開いてAstroImageJのページ にアクセス
  • 「install Version 6 now」をクリック
  • 表示されるページの指示にしたがってインストールする

以下，英語を読みたくない人のために

AstroImageJソースの入手

  • AstroImageJのソース
  • Choose platoformで自動的にOSを判定してくれているはずなので適するバージョンをダウンロード。
  • Windowsの人：Download AsteroImageJ 6.0.10.00 for Windows
  • Downloadしたファイルをダブルクリックしたらインストールしてくれるはず。

実行

  • 「AstroImageJ」をダブルクリックして起動してみる
    • アプリケーションが起動したらインストール成功
    • 「VCRUNTIME140.dll が見つからない」と言われたら，「Visual Studio 2015 の Visual C++ 再頒布可能パッケージ」をインストールする

Visual Studio 2015 のインストール

  • Microsoftダウンロードセンターからソースを入手する
    • Visual Studio 2015 の Visual C++ 再頒布可能パッケージ

AstroImageJ のインストール (Macの場合)

  • ブラウザを開いてAstroImageJのページ にアクセス
  • 「install Version 6 now」をクリック
  • 表示されるページの指示にしたがってインストールする

AstroImageJソースの入手

  • AstroImageJのソース
  • Mac(Appleチップ) の場合
    • Choose platoformで自動的にOSを判定してくれているはずなので適するバージョンをダウンロード。
    • Download AsteroImageJ 6.0.10.00 for Mac(Arm)
  • Mac(Intelチップ)の場合
    • Download AsteroImageJ 6.0.10.00 for Mac(Intel)

インストール

  • Downloadしたファイルをダブルクリックしたらインストールしてくれるはず。

実行

  • 「AstroImageJ」を起動してみる
    • 正しくインストールされていれば「Launchpad」に「AstroImageJ」のアイコンが追加されるので,それをクリックする
    • 「アプリケーション」のフォルダを開いて,「AstroImageJ」をダブルクリックしてもよい
